# Presentation review checklist

Run this checklist after the deck builds and after you inspect the export.

## Argument

- [ ] The deck has one thesis.
- [ ] The opening states why the topic matters to this audience.
- [ ] Each slide advances one claim.
- [ ] The slide titles form a coherent argument.
- [ ] Evidence appears near the claim that it supports.
- [ ] The close states a decision, action, or implication.

## Content

- [ ] Every number has a source or a clear derivation.
- [ ] Every quote has a source.
- [ ] Every acronym is necessary and defined.
- [ ] Every code example supports the talk.
- [ ] Speaker notes contain detail that the slide does not need.
- [ ] The planned slide count fits the presentation duration.

## Visual system

- [ ] Type scale and alignment are consistent.
- [ ] Color use is consistent and accessible.
- [ ] Visuals support claims.
- [ ] Charts have readable labels and honest scales.
- [ ] Diagrams show the intended relationship.
- [ ] Repeated layouts do not make the deck monotonous.
- [ ] Empty space separates ideas.

## Slidev behavior

- [ ] The deck loads without a browser console error.
- [ ] Every local asset resolves.
- [ ] Mermaid diagrams and Vue components render.
- [ ] Click steps reveal content in the intended order.
- [ ] Presenter notes appear on the correct slide.
- [ ] The overview shows no overflow or accidental blank slide.

## Export

- [ ] The required PDF, PPTX, PNG, or static build exists.
- [ ] The export uses the correct aspect ratio.
- [ ] Fonts render as expected.
- [ ] No text, code, image, or footer clips.
- [ ] Links and attribution text are correct.
- [ ] The final file name and metadata match the request.
