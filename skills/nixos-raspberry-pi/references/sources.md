  <https://github.com/pftf/RPi4>
- Raspberry Pi 4 UEFI releases:
  <https://github.com/pftf/RPi4/releases>
- NixOS on ARM:
  <https://wiki.nixos.org/wiki/NixOS_on_ARM>
- Disko image generation:
  <https://github.com/nix-community/disko/blob/master/docs/disko-images.md>
- Nix cores and jobs:
  <https://nix.dev/manual/nix/latest/advanced-topics/cores-vs-jobs>
- Nix distributed builds:
  <https://nix.dev/tutorials/nixos/distributed-builds-setup.html>
- QEMU user-mode documentation:
  <https://www.qemu.org/docs/master/user/main.html>
- OpenZFS administration:
  <https://openzfs.github.io/openzfs-docs/>
- bmaptool:
  <https://github.com/yoctoproject/bmaptool>
- systemd-boot:
  <https://www.freedesktop.org/software/systemd/man/latest/systemd-boot.html>

Prefer commit-pinned source files when a repository lock determines behavior.
Record the retrieval date for unversioned documentation.
