# Honesty checklist

Run this after the deck builds and after you inspect the export. Run it against
the rendered pages, not the source. A claim that reads as careful in markdown
can read as a boast at 2.4 rem.

## Numbers

- [ ] Every figure carries an evidence class.
- [ ] No `unratified` figure appears on any slide.
- [ ] No self-derived quotient appears. The source values appear instead.
- [ ] Every mixed subtotal shows a band, not a point estimate.
- [ ] Each price says whether a buyer agreed to it or the arithmetic produced it.
- [ ] A reader can reproduce every `calculation` from the inputs shown.

## Claims

- [ ] Every status claim carries a date.
- [ ] No claim runs ahead of the milestone it cites. Check the tracker, not the memory.
- [ ] Each result states what it does not prove.
- [ ] Each external benchmark is labeled as external, with the differences named.
- [ ] The deck states plainly where there is no contract, no date, and no revenue.
- [ ] A live system slide shows both what runs now and what is not yet true.

## Argument

- [ ] The headlines alone carry the argument.
- [ ] Each headline states a claim, not a topic.
- [ ] Each slide advances one claim.
- [ ] Evidence sits beside the claim it supports.
- [ ] The final slide states the ask, ranked.
- [ ] The deck names the one number it cannot generate internally.

## People

- [ ] Each named person matches the durable record — role, discipline, employer.
- [ ] Each employer that has no relationship with the venture says so.
- [ ] No quote is attributed to a speaker the source cannot identify.
- [ ] Each person's short form is the one they use.

## Delivery

- [ ] The slide count fits the stated duration.
- [ ] The speaker notes carry the narration when the deck must stand alone.
- [ ] Every acronym is necessary and defined before its second use.
- [ ] Every asset has its source and attribution recorded.
- [ ] No text, image, or footer clips in the export.

## The last question

Read the deck as the most skeptical person in the room. Find the weakest number.
Ask whether the deck already tells the reader that it is weak.

If it does not, the deck is not finished.
