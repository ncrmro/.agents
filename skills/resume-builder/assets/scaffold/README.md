# Resume source

This directory is the canonical source for career facts, targeted resume
variants, and publication state.

## Rules

- Record facts once in `profile.md`, `work-history/`, or `projects/`.
- Give reusable accomplishments stable claim IDs.
- Build variants by selecting claim IDs; do not copy facts into variants.
- Mark every record and claim `public`, `resume-only`, or `private`.
- Treat `exports/` and websites as derived outputs.
- Link application-specific variants to the existing application record.

The human-invoked `resume-builder` skill owns the full workflow and validation
rules.
